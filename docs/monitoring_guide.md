# Monitoring & Logging Configuration Guide

This document describes how to analyze hardware metrics, REST API payloads, and query audit log events using Prometheus, Grafana, and the ELK stack.

---

## 1. Metrics Surveillance (Prometheus & Grafana)

The metrics monitoring configuration is built automatically during `docker-compose up`.

### Key Metrics Exported
Our backend REST API exports raw values to the `/metrics` path using `prom-client`:
- `process_cpu_seconds_total`: Node process CPU consumption.
- `process_resident_memory_bytes`: RAM footprint.
- `http_requests_total`: Counter tracking API executions, tagged with method, route, and status.
- `http_request_duration_seconds`: Response latency histograms.

### Visualizing in Grafana
1. Open `http://localhost:3000` (User: `admin` / Password: `admin`).
2. Go to **Dashboards** menu. Three dashboards are auto-provisioned:
   - **GlobalMedX - Application Dashboard:** Displays API call throughput, latency averages, and process heap size.
   - **GlobalMedX - Infrastructure Dashboard:** Displays event loop lag and Resident Memory usage.
   - **GlobalMedX - Outbreak Dashboard:** Tracks simulator launch operations and total disease reports.

## 2. Centralized Logs (ELK Stack)

Structured JSON log pipelines parse Express activity logs.

### Operational Logs Pipeline
```
[ Winston Logger ] ---> [ TCP Port 5044 ] ---> [ Logstash ] ---> [ Elasticsearch ] ---> [ Kibana Panel ]
```

### Ingesting with Logstash
Logs are ingested on TCP port 5044 using JSON codec format as configured in [logstash.conf](file:///Users/adarshsingh/Sem%204%20/Devops/globalmedx/elk/logstash/logstash.conf).

### Accessing Kibana Logs Dashboard
1. Open the Kibana console at `http://localhost:5601`.
2. Go to **Management** -> **Kibana** -> **Index Patterns** -> Select **Create index pattern**.
3. Define index pattern match: `globalmedx-logs-*` -> Set primary time filter: `@timestamp` -> Click **Create**.
4. Go to **Discover** panel to search and query real-time JSON logs generated by database writes and simulation runs.
